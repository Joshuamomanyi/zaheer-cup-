# Zaheer Cup Golden Pitch

Project Title: Ebunda Cup - Official Tournament Website (Nyaribari Masaba)

Role: Experienced Web Designer & Developer (expert in React, Next.js, and Tailwind CSS).

Objective: Design and build a modern, sleek, and high-performance web application for the 'Ebunda Cup' football tournament. This site must look incredibly polished and professional, rivaling top-tier sports league websites.

Core Vision: The 'Ebunda Cup' is a prestigious football tournament in Nyaribari Masaba, held annually in August and December. It features both Men's and Women's categories. While celebrating sport, the app's critical underlying function is as a lead magnet and data capture engine for the tournament organizer, Eng. Moses Oira (populary known as 'Ebunda'), gearing up for his 2027 Parliamentary election bid. The site must serve as the central hub for registration, schedules, results, streaming, news, and political communication. Data security and privacy are paramount.

Phase 1: Tech Stack & Architecture

Framework: Next.js (for performance, SEO, and developer experience).

Styling: Tailwind CSS (for modern, responsive utility-first design).

Database: A robust database (like PostgreSQL or Supabase) is essential for storing team, player, and contact data. Crucially, integrate a field in the registration form to capture player phone numbers with an opt-in for SMS campaigns.

CMS (Optional but Recommended): A headless CMS (like Sanity or Contentful) to manage news, gallery, and schedule data.

Form Handling: A secure and efficient system for registration forms.

Media Hosting: A solution (e.g., Cloudinary or Vercel Blob) for image and video content.

Hosting: Deploy on Replit with an optimized build process.

Phase 2: Branding & Design Language

Reference Image: Ebunda cup.jpg The screenshot provided image_0.png (Ebunda cup.jpg) features a dark theme, a bright yellow/gold accent color, and clean typography with an image-heavy, immersive layout. This exact style must be replicated and enhanced for the Ebunda Cup site.

Primary Palette: Very dark grey/near-black backgrounds (like in Ebunda cup.jpg).

Accent Color: A vibrant, impactful yellow/gold (#FFD700 or similar), used sparingly for CTAs, buttons, and high-priority highlights.

Typography: Modern, clean, sans-serif fonts (e.g., Inter, Montserrat, or Roboto) for readability. Hierarchy is key.

Visual Style: Use high-quality, professional photography. Think dramatic, slow-motion football action (similar to the blur in Ebunda cup.jpg but clearer), passionate fans, and clean, defined UI components. Use gradients and overlays to create depth against the dark background. The entire site must look premium and premium.

Phase 3: Site Structure & Page Sections (Single Page Application or Multi-Page Setup)

1. Header (Navbar)

Logo: A sleek 'Ebunda Cup' logo in the top left.

Navigation Links: Home, Live, Schedule, Results, Standings, Teams, Gallery, News, Ebunda MP 2027.

Primary CTA Button: "Register Your Team" (in the accent yellow/gold).

2. Hero Section (Home Page)

Image: A high-resolution, captivating image of Nyaribari Masaba scenery blended with professional football action. Use a dark gradient overlay.

Headline: "Ebunda Cup: The Pride of Nyaribari Masaba. Register Now!" (Dynamic, exciting text).

Subheadline: "Celebrating Sport, Uniting Community. August & December 2024. Men & Women's Categories."

Primary CTA Buttons: "Team Registration" and "Watch Live".

3. Section: Live & Upcoming Matches (Home Page, Sliding Cards)

This section is high priority, immediately following the Hero.

Layout: A horizontally scrolling (on desktop and mobile) container of match cards.

Card Details:

Match Status (Live, Upcoming, Complete).

Date and Time.

Competing Teams (Logos and Names).

"Watch Live" button (leads to the Live page or displays an overlay).

"Get Tickets/Reminders" button (potential future feature).

4. Additional Home Page Sections (To be determined by Replit, suggestions below):

Ebunda MP 2027 Preview: A teaser for the dedicated page, introducing Eng. Moses Oira and his vision, linking to the full page.

Gallery Preview: A showcase of top images, linking to the full Gallery page.

Latest News: Headlines from the News page.

Top Scorer/League Stats Leaders: Highlighting outstanding players.

5. "Live" Page

This page will feature embedded video streams. Provide clear sections for:

Current Live Stream (Primary Player).

Upcoming Streams.

Archived Match Videos.

Feature Request: Implement a live chat function for fan interaction.

6. "Schedule" Page

A user-friendly, filterable (by date, gender, team) view of all tournament matches.

7. "Results" Page

Comprehensive match reports and final scores. Include an dynamic interactive timeline.

8. "Standings" (League Table) Page

A dynamic league table for both Men's and Women's categories. Include common table headers: Pos, Team, MP (Matches Played), W, D, L, GF, GA, GD (Goal Difference), Pts.

9. "Teams" Page (Clubs/Teams Hub)

A dedicated page for each team in the tournament.

List of Teams (Include ALL): Getacho, Chibwobi, Omobera, Kiomiti, Getare, Ikenye, Nyamesocho, Mesabisabi, Raganga, Masabo, Chironge, Nyangonda, Geteri, Emonga.

Team Page Features: Squad List (Player names, photos), Team History, Results, Upcoming Fixtures.

10. "Gallery" Page

A visually impressive grid of high-quality photos capturing the tournament's best moments. Filter by event, year, gender, etc. Crucial for long-term branding and memory preservation.

11. "News" Page

A section for articles, match reports, player spotlights, and community news.

12. "Ebunda MP 2027" Page

Title: "Eng. Moses Oira (Ebunda) - Your Representative for Nyaribari Masaba 2027"

Content:

Biography of Eng. Moses Oira.

Key campaign pillars and vision for Nyaribari Masaba.

Contact information.

A prominent call-to-action for supporting his campaign (e.g., volunteer sign-up).

This page must clearly explain his motivation for organizing the tournament and link back to the data-capture registration process.

13. Registration Form (The Data Capture Engine)

Key Fields: Team Name, Gender (Men/Women), Captain Name, Captain Email, Captain Phone, Player Names (Multiple fields).

CRITICAL FEATURE: For every player, include a mandatory phone number input field.

MANDATORY OPT-IN: Add a checked checkbox for: "I and all registered players opt-in to receive communication, including SMS updates, about the Ebunda Cup and related community initiatives, including Eng. Moses Oira's MP 2027 campaign."

Submission Handling: Securely store all registered data. Ensure privacy compliance (like GDPR if applicable, but definitely Kenyan data protection laws).

14. Footer

Logo & Contact Info: Tournament logo, contact details.

Sponsors: Dedicated section for sponsor logos.

Social Media Icons: Integrate sleek, official icons for Facebook and X (formerly Twitter).

Legal: Copyright info, Privacy Policy link.

Phase 4: Non-Functional Requirements & Polish

Mobile Responsiveness: The site must look and perform flawlessly on all devices (mobile, tablet, desktop). Prioritize mobile-first design.

Performance Optimization: Implement techniques like lazy loading images, code splitting, and browser caching to ensure fast load times.

SEO Optimization: Use proper semantic HTML, title tags, meta descriptions, and schema markup to maximize search engine visibility.

Accessibility (a11y): Ensure the site is accessible to users with disabilities, adhering to WCAG standards.

Analytics: Integrate analytics (like Google Analytics) to track site traffic, user behavior, and conversion metrics.

Execution: Lovable, please begin by setting up the project structure and generating a conceptual home page design based on these detailed requirements. The visual fidelity and performance should be top priorities from the outset. Referencing image_0.png ('Ebunda cup.jpg') as the definitive style guide is paramount.
